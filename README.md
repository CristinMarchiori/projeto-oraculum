# Projeto Oraculum

Crie uma aplicação web responsiva para acompanhamento de notas de manutenção industrial.

A aplicação deve possuir:

1. Um cabeçalho com o título "Painel de Manutenção".

2. Quatro indicadores:

 - Notas abertas;

 - Notas em andamento;

 - Notas concluídas;

 - Notas críticas.

3. Uma tabela com:

 - Número da nota;

 - Máquina;

 - Descrição;

 - Responsável;

 - Prioridade;

 - Status;

 - Data de abertura.

4. Filtros por máquina, prioridade e status.

5. Um campo de pesquisa por número da nota ou descrição.

6. Um formulário para cadastrar uma nova nota.

7. Gráficos mostrando:

 - Quantidade de notas por máquina;

 - Distribuição das notas por status.

Utilize somente dados fictícios.

Não crie login, banco de dados ou integrações nesta primeira versão.

Use um design industrial, profissional, limpo e responsivo.

Utilize tons de azul, cinza e branco.

Todo o conteúdo deve estar em português do Brasil.
